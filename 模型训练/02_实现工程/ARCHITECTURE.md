# 报销审计三模块工程结构

共享Qwen3-VL-8B底座负责材料读取与4096维特征编码，读取LoRA完成领域事实适配。三个神经模块使用512维审计表示、256维内部网络和8个角色槽，分别执行政策关系判断、证据贡献核验和局部循环校正。

| 层次 | 路径 | 职责 |
|---|---|---|
| 神经模块 | `audit_engine/models/` | 共享投影、关系判断、双向引用头、局部校正 |
| 政策与金额 | `audit_engine/policy/` | 类型化比较、来源依赖、精确十进制金额计算 |
| 材料读取 | `audit_engine/readers/` | 原始文档解析、整图与完整页面读取、引用核验和冻结编码 |
| 训练 | `audit_engine/training/` | 有效标签损失、B1/B2/B3/B4/C阶段优化、扰动恢复 |
| 推理 | `audit_engine/inference/` | 关系与整材料屏蔽、最多2轮局部校正、F/B/T与复核任务 |
| 命令入口 | `code/scripts/` | 数据转换、验证、训练、预测、评分及报告 |

运行配置为 `configs/patent_delivery.yaml`，读取LoRA训练配置为 `configs/patent_reader_delivery.yaml`。入口默认使用对应交付配置；预测读取checkpoint保存的训练配置及阈值。

原始材料保存在 `data_raw/`，当前输入、标签及特征保存在 `data/三模块交付_20261027/`，新运行写入 `work/`。训练监督和参考答案分别由训练与离线评分入口读取，推理依据当前申请、原始材料和政策执行。
