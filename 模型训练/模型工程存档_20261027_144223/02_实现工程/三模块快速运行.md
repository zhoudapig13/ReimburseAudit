## 数据接口

`data/patent_full/cases.jsonl`：运行输入，包含申请、材料、政策条件、带引用的类型化读数、互不重叠的金额单元。

`data/patent_full/annotations.jsonl`：单独保存条件状态、材料关系和支持/冲突引用标签。每条记录绑定工作流、条件、原件分组、固定划分和 case SHA256。pending/excluded 不参与监督，未核验位置保持掩码。

`data/patent_full/condition_review_queue.jsonl`：151例的条件核验清单。需要补齐政策适用范围、角色、比较操作、金额单位、违规后果、材料读数及引用。金额单元中的共享上限先按组归并。核验后更新 cases，再生成与新 case 摘要一致的 annotations。

原件修改后重新解析、更新引用与读数、重建特征。B4 增强样本记录 `augmentation_of`，沿用原始材料的 source_family_id 和划分。

```bash
python code/scripts/patent_pipeline.py validate \
  --cases data/patent_full/cases.jsonl \
  --annotations data/patent_full/annotations.jsonl \
  --partitions data/patent_full/partitions.jsonl

python code/scripts/patent_pipeline.py split \
  --cases data/patent_full/cases.jsonl \
  --partitions data/patent_full/partitions.jsonl --output data/patent_full
```

合同示例和标签格式可查看工程示例目录的 `cases.jsonl`、`annotations.jsonl`，完整字段见 JSON Schema。已有整单参考答案继续用于独立评测。

## 短训练

`configs/patent_fast.yaml` 保持4096维底座、512维审计向量、256维内部宽度、8个角色槽和最多2轮局部校正。底座冻结，特征编码一次后复用。B1训练1轮、B2训练1轮、B3联合训练2轮、C训练2轮；存在原件核验过的事实增强样本时，B4训练1轮。验证集选择 checkpoint；C按自然错误的净纠正率选点，并记录误改数量。

准备固定版本 `Qwen/Qwen3-VL-8B-Instruct`：`0c351dd01ed87e9c1b53cbc748cba10e6187ff3b`。`MODEL_PATH` 指向完整本地底座。

```bash
python code/scripts/patent_pipeline.py encode \
  --cases data/patent_full/cases.jsonl --features data/patent_features \
  --model-path "$MODEL_PATH" --device cuda:0

python code/scripts/patent_pipeline.py train \
  --cases data/patent_full/cases.jsonl \
  --annotations data/patent_full/annotations.jsonl \
  --features data/patent_features --config configs/patent_fast.yaml \
  --output runs/patent_fast --device cuda:0
```

编码支持分片：5张空闲卡分别执行 `--shard 0/5 --device cuda:0` 至 `--shard 4/5 --device cuda:4`，使用同一个 features 目录。每个材料仅使用自身的文本或图像视图，长文本分块后聚合；缓存绑定版本、编码参数及输入摘要。

产物包括 `audit_heads.pt`、各阶段 checkpoint、逐轮日志和 `training_summary.json`。正式训练要求真实底座特征、已核验的训练和验证条件标签。三个核心模块均发生实际优化后，checkpoint 才能通过推理入口的完整性检查。

## 预测与评测

```bash
python code/scripts/patent_pipeline.py predict \
  --cases data/patent_full/validation_cases.jsonl \
  --features data/patent_features --checkpoint runs/patent_fast/audit_heads.pt \
  --output runs/patent_fast/validation_predictions.jsonl --device cuda:0

python code/scripts/evaluate_patent_predictions.py \
  --predictions runs/patent_fast/validation_predictions.jsonl \
  --gold data/labels_private/validation_reference_targets.jsonl \
  --output runs/patent_fast/validation_accuracy.json
```

准确率按 FLAG 与 max_legal 同时正确计算。缺失、读取失败、格式错误均保留在总样本数中。预测入口不读取参考答案；计分入口只读取已落盘的预测和参考答案。

消融使用同一份 checkpoint 和输入：`--no-correction` 关闭局部校正；`--ablation no_policy_comparison` 关闭确定性比较特征；`--ablation no_contribution` 关闭贡献模块，以关系概率作为引用分数。每种设置使用不同输出文件。
