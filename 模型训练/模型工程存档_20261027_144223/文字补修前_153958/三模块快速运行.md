# 三模块运行说明

已完成三个核心模块及配套材料读取LoRA的训练和联合运行验证。
微调后三模块系统准确率为 **52.17%（12/23）**，FLAG与最大合规金额同时正确。

所有命令在本工程目录执行，使用支持RTX5090的Python 3.12及PyTorch环境。下文的 `python` 应指向安装了 `requirements.lock.txt` 依赖的解释器。

```bash
export TMPDIR="$PWD/work/tmp"
export PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=4 MKL_NUM_THREADS=4
mkdir -p "$TMPDIR"
```

联合checkpoint：`models/报销审计_三模块/checkpoint_20261027_5217/audit_heads.pt`。
配套读取LoRA：同目录下的 `reader_lora/`。联合checkpoint同时保存共享投影及关系、贡献、局部校正三个模块；B1、B2、B3、B4、C各阶段checkpoint同时保留。

## 使用配套特征推理

```bash
python code/scripts/patent_pipeline.py predict \
  --cases data/三模块交付_20261027/validation_cases.jsonl \
  --features data/三模块交付_20261027/features \
  --checkpoint models/报销审计_三模块/checkpoint_20261027_5217/audit_heads.pt \
  --output work/predictions.jsonl --device cpu

python code/scripts/evaluate_patent_predictions.py \
  --predictions work/predictions.jsonl \
  --gold data/labels_private/validation_reference_targets.jsonl \
  --output work/score.json
```

输出文件需尚不存在，以保留每次运行的记录。完整三模块推理默认启用，不添加关闭模块的消融参数。

## 读取器和底座特征

固定底座revision：`0c351dd01ed87e9c1b53cbc748cba10e6187ff3b`。设置 `MODEL_PATH` 为实际的本地底座路径。运行配置已绑定交付的读取LoRA。

```bash
python code/scripts/patent_pipeline.py encode \
  --cases data/三模块交付_20261027/dataset/reader_cases.jsonl \
  --features work/encoded_features --config configs/patent_delivery.yaml \
  --model-path "$MODEL_PATH" --device cuda:0
```

输入、政策条件、来源证明、监督标签及固定划分保存在 `data/三模块交付_20261027/`。其中监督与运行输入分开保存，参考答案由离线评分进程读取。改变源材料或读取LoRA后，需刷新相关读取、特征和输入摘要。

## 继续训练三个模块

```bash
python code/scripts/patent_pipeline.py train \
  --cases data/三模块交付_20261027/dataset/reader_cases.jsonl \
  --annotations data/三模块交付_20261027/dataset/annotations.jsonl \
  --features data/三模块交付_20261027/features \
  --config configs/patent_delivery.yaml \
  --initial-checkpoint models/报销审计_三模块/checkpoint_20261027_5217/audit_heads.pt \
  --output work/continued_training --device cuda:0
```

配置包含B1/B2/B3/B4/C，按阶段冻结并更新相应模块。输出到新目录。若再次微调读取LoRA，应使用新的特征目录，并在同一固定底座、同一编码规则下使用 `--adapt-reader-encoder` 重新训练三个模块。
